## How to read status and history

The canonical programme-status page owns current public release facts. A procedure describes how to qualify a future candidate; it does not imply a current blocker or grant implementation authority. Dated measurements and audit-era sections retain the meaning of their own snapshots. The original 95%/90% semantic targets remain missed even though release delivery is complete.

Private operator state, corpus bodies, audit packets and session handoffs are intentionally excluded from the selected public repository. Their historical task checkboxes are not a public implementation queue. Maintainers use the local root STATUS/PLAN and canonical machine state to resume only the latest owner-authorized scope.
